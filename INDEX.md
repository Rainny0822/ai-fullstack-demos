# Portfolio Demo Descriptions

Hireable demo projects showcasing AI, full-stack, and SaaS engineering skills. Use these titles, descriptions, and skills for portfolio uploads.

## 1. LLM Chat Kit

**Path:** `/workspace/contra-portfolio/llm-chat-kit`  
**Title:** LLM Chat Kit — Streaming Chat UI (Mock Mode)

**Description:**  
A Next.js App Router + TypeScript chat interface with token-style streaming replies. Runs fully in mock mode with no API key, so you can demo chat UX patterns immediately. Swap the route handler for a real LLM when you are ready to integrate production providers.

**Skills:** Next.js, TypeScript, React, Streaming UI, API Routes

## 3. RAG Doc Q&A

**Path:** `/workspace/contra-portfolio/rag-doc-qa`  
**Title:** Document Q&A with Mock RAG Retrieval

**Description:**  
A simple Next.js document Q&A demo with in-memory keyword retrieval over sample docs. Illustrates the retrieve-then-answer flow without a vector database or LLM API key. Includes sample corpus files and a JSON ask API for easy extension to real embeddings later.

**Skills:** Next.js, TypeScript, RAG, Information Retrieval, API Design

## 6. RAG Knowledge Base

**Path:** `/workspace/demos/rag-knowledge-base`  
**Title:** RAG Knowledge Base — Semantic Search Demo

**Description:**  
A Next.js + TypeScript demonstration of Retrieval-Augmented Generation (RAG) with semantic search over a knowledge base. Features mock keyword-based retrieval that simulates vector embeddings, contextual answer generation from retrieved documents, relevance scoring, and a clean search interface. Includes 12 sample documents across development, AI/ML, and DevOps topics. No vector database or API keys needed — perfect for showcasing RAG architecture.

**Skills:** Next.js, TypeScript, RAG, AI/ML, Semantic Search, Information Retrieval
