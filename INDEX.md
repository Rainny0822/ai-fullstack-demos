## 3. RAG Doc Q&A

**Path:** `/workspace/contra-portfolio/rag-doc-qa`  
**Title:** Document Q&A with Mock RAG Retrieval

**Description:**  
A simple Next.js document Q&A demo with in-memory keyword retrieval over sample docs. Illustrates the retrieve-then-answer flow without a vector database or LLM API key. Includes sample corpus files and a JSON ask API for easy extension to real embeddings later.

**Skills:** Next.js, TypeScript, RAG, Information Retrieval, API Design

## 4. Automation Webhook Starter

**Path:** `/workspace/contra-portfolio/automation-webhook`  
**Title:** FastAPI Webhook & Automation Starter
