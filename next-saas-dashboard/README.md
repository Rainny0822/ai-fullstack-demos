# Next SaaS Dashboard

Portfolio demo: a minimal Next.js + TypeScript SaaS dashboard with sidebar navigation, metric cards, a placeholder chart, and a settings page.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## What's included

- Sidebar: Overview / Settings
- Metric cards (sample MRR, users, churn, NPS)
- CSS bar chart placeholder (no chart library)
- Settings form UI (non-persisting)

This is a **personal portfolio demo**, not a paid client project.
